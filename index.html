How to read this

  • Oct–Jul basis. Fiscal years run Oct–Sep. Comparisons use the Oct–Jul window so a fiscal year in progress can be compared like-for-like with completed years, without the heavy August–September award season distorting it.
  • The dollar series is outlier-driven. Institute-scale awards (e.g. the mathematical-sciences institutes renewal cycle) can be 15–20% of a year's dollars in the top three awards alone, so the stacked dollars chart separates the top 3 from the rest — year-over-year swings in the total largely track the institute cycle, not the research-grant base.
  • Standard vs continuing grants. A shift in NSF practice from continuing to standard grants lowers the new-continuing-award count without necessarily cutting funding — interpret the mechanism chart before reading the headline count as a cut.
  • Amendment bias. Intended totals are read as currently stated, including later upward amendments. Older cohorts have had longer to accumulate them, which biases recent years low by an unmeasured amount.
  • Pagination fault, handled. The NSF API silently drops ~5% of records on large paginated queries. The pull script keeps every query window small (bisecting as needed) and cross-checks against an independently verified baseline. Data refreshes weekly via GitHub Actions; the full award-level dataset is in awards.csv.
